## sort



下面按**容器类型**分类，把 C++ 中常见的排序写法和例子列全。

## 一、普通数组（C 风格）

```cpp
int a[5] = {3, 1, 4, 1, 5};

// 升序
sort(a, a + 5);                    // 1 1 3 4 5

// 降序
sort(a, a + 5, greater<int>());    // 5 4 3 1 1

// 自定义：按绝对值降序
sort(a, a + 5, [](int x, int y) {
    return abs(x) > abs(y);
});

// 1. 先定义一个普通函数 bool类型
bool cmp(int a, int b) {
    return a > b;   // 降序  表示左边a要大于b
}

int main() {
   sort(a, a + 5, cmp); //不能写错cmp() 这是调用，不是传参
}
```

注意：**指针范围是 `[a, a + n)`**，右端是 `a + n`，不是 `a + n - 1`。

## 二、`vector<int>`

```cpp
vector<int> v = {3, 1, 4, 1, 5};

// 升序
sort(v.begin(), v.end());                    // 1 1 3 4 5

// 降序
sort(v.begin(), v.end(), greater<int>());    // 5 4 3 1 1

sort(v.begin(), v.end(), cmp); 

// 或反向迭代器
sort(v.rbegin(), v.rend());                  // 5 4 3 1 1
```

## 三、`vector<string>`

```cpp
vector<string> v = {"banana", "apple", "cherry"};

// 字典序升序
sort(v.begin(), v.end());                    // apple banana cherry

// 字典序降序
sort(v.begin(), v.end(), greater<string>());

// 按长度升序，长度相同按字典序
sort(v.begin(), v.end(), [](const string& a, const string& b) { // &避免拷贝 const 只读防止误改
    if (a.size() != b.size()) return a.size() < b.size();
    return a < b;
});
```

## 四、二维 `vector<vector<int>>`

默认按**第一列字典序**排：

```cpp
vector<vector<int>> v = {{3,1}, {1,5}, {2,4}};

// 默认：按第一列升序，第一列相同看第二列
sort(v.begin(), v.end());
// {{1,5}, {2,4}, {3,1}}
```

按第二列升序：

```cpp
sort(v.begin(), v.end(), [](const vector<int>& a, const vector<int>& b) {
    return a[1] < b[1];
});
```

多关键字：

```cpp
// 第一列升序，第一列相同第二列降序
sort(v.begin(), v.end(), [](const vector<int>& a, const vector<int>& b) {
    if (a[0] != b[0]) return a[0] < b[0];
    return a[1] > b[1];
});
```

## 五、二维普通数组

```cpp
int a[3][2] = {{3,1}, {1,5}, {2,4}};

// 按第二列升序
sort(a, a + 3, [](const int* x, const int* y) {
    return x[1] < y[1];
});
```

## 六、`pair`

`pair` 自带比较：先比 `first`，再比 `second`。

```cpp
vector<pair<int,int>> v = {{3,1}, {1,5}, {2,4}};

// 默认：first 升序，first 相同 second 升序
sort(v.begin(), v.end());
// {{1,5}, {2,4}, {3,1}}

// 按 second 升序
sort(v.begin(), v.end(), [](const auto& a, const auto& b) {
    return a.second < b.second;
});
```

## 七、结构体

```cpp
struct Student {
    string name;
    int score;
};

vector<Student> stu = {{"Tom",90}, {"Amy",95}, {"Bob",90}};

// 按分数降序，分数相同按名字升序
sort(stu.begin(), stu.end(), [](const Student& a, const Student& b) {
    if (a.score != b.score) return a.score > b.score;
    return a.name < b.name;
});
```

## 八、`deque`

用法和 `vector` 一样：

```cpp
deque<int> d = {3, 1, 4, 1, 5};

sort(d.begin(), d.end());                    // 升序
sort(d.begin(), d.end(), greater<int>());    // 降序
```

## 九、`list`

`list` **不能用 `std::sort`**（因为它不支持随机访问迭代器），要用自己的 `list::sort`：

```cpp
list<int> lst = {3, 1, 4, 1, 5};

// 升序
lst.sort();                                   // 1 1 3 4 5

// 降序
lst.sort(greater<int>());                     // 5 4 3 1 1

// 自定义
lst.sort([](int a, int b) { return a > b; });
```

## 十、`queue` / `stack` / `priority_queue`

**`queue` 和 `stack` 不能排序**，它们只允许访问队首/栈顶，没有迭代器。

- 要排序：先倒进 `vector`，排完再放回
- 或者直接用 **`priority_queue`**

```cpp
// queue 不能直接 sort，先转 vector
queue<int> q;
// ... 填入数据
vector<int> tmp;
while (!q.empty()) { tmp.push_back(q.front()); q.pop(); }
sort(tmp.begin(), tmp.end());
for (int x : tmp) q.push(x);   // 放回
```

### `priority_queue`（优先队列）

**默认大顶堆**（最大的在顶部）：

```cpp
priority_queue<int> pq;                 // 大顶堆，top 是最大值
priority_queue<int, vector<int>, greater<int>> minHeap;  // 小顶堆
```

自定义：

```cpp
struct Node { int val; };
auto cmp = [](const Node& a, const Node& b) {
    return a.val > b.val;   // 注意：> 得到小顶堆
};
priority_queue<Node, vector<Node>, decltype(cmp)> pq(cmp);
```

**注意**：`priority_queue` 的比较含义和 `sort` **相反**：

- `sort`：`a < b` 升序
- `priority_queue`：`a < b` 得到**大顶堆**（大的先出）

## 十一、`set` / `map`

它们**自动有序**，不能也不需要对整体排序，但可以自定义排序规则：

```cpp
// set 默认升序
set<int> s = {3, 1, 4};

// 降序 set
set<int, greater<int>> s2 = {3, 1, 4};

// map 默认按 key 升序
map<int, string> mp;

// 降序 map
map<int, string, greater<int>> mp2;
```

## 十二、`unordered_map` / `unordered_set`

**无序**，不能直接排序。

要排序：**先转成 `vector`，再排**：

```cpp
unordered_map<string, int> mp = {{"b",2}, {"a",1}, {"c",3}};

vector<pair<string,int>> v(mp.begin(), mp.end());

// 按 value 降序
sort(v.begin(), v.end(), [](const auto& a, const auto& b) {
    return a.second > b.second;
});
```

## 十三、总表

| 容器             | 排序方式                   | 能否直接 `sort` |
| ---------------- | -------------------------- | --------------- |
| 普通数组         | `sort(a, a+n)`             | ✅               |
| `vector`         | `sort(v.begin(), v.end())` | ✅               |
| `deque`          | `sort(d.begin(), d.end())` | ✅               |
| `string`         | `sort(s.begin(), s.end())` | ✅               |
| `list`           | `lst.sort()`               | ❌ 用成员函数    |
| `queue`          | 转 `vector` 再排           | ❌               |
| `stack`          | 转 `vector` 再排           | ❌               |
| `priority_queue` | 构造时给比较器             | ❌ 自动维护      |
| `set` / `map`    | 构造时给比较器             | ❌ 自动有序      |
| `unordered_*`    | 转 `vector` 再排           | ❌ 无序          |

## 十四、一句话总结

> - **连续容器**（数组、`vector`、`deque`、`string`）：用 `std::sort`
> - **`list`**：用 `lst.sort()`
> - **`queue` / `stack`**：不能排，先转 `vector`
> - **`priority_queue`**：构造时给比较器，比较含义和 `sort` **相反**
> - **`set` / `map`**：自动有序，构造时给比较器
> - **`unordered_*`**：先转 `vector` 再排
