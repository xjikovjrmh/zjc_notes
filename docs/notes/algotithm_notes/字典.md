# 字典

在c++中分为两种

## 区别

|           | `map`         | `unordered_map`      |
| :-------- | :------------ | :------------------- |
| 底层      | 红黑树        | 哈希表               |
| 是否有序  | ✅ 按 key 排序 | ❌ 无序               |
| 查找/插入 | O(log n)      | 平均 O(1)，最坏 O(n) |
| 头文件    | `<map>`       | `<unordered_map>`    |
| 需要哈希  | 不需要        | key 要可哈希         |

**选择**：要按 key 有序遍历用 `map`，只关心查找速度用 `unordered_map`。

key 要保证唯一，每个可以只对应一个value

### 二、创建

```cpp
#include <map>
#include <unordered_map>
#include <string>

map<string, int> mp;              // key: string, value: int
unordered_map<int, int> ump;      // key: int,    value: int

// 直接初始化
map<string, int> mp2 = {{"Tom", 90}, {"Amy", 95}};
unordered_map<string, int> ump2 = {{"a", 1}, {"b", 2}};
```

### 4三、插入修改

```cpp
//1.下标插入
mp["Tom"]=90;// 无key则插入，有则覆盖
//2.insert
mp.insert({"Amy",95});//key存在则插入失败,88
//等价写法
mp.insert(make_pair("Bob",88));
//3.emplace 效率高
mp.emplace("Cat",77);
//4.insert_or_assign( c++17 存在就覆盖)
mp.insert_or_assign("Tom",100);



```

### 四、查找

```cpp
// 1. count：返回 0 或 1
if (mp.count("Tom")) { /* 存在 */ }

// 2. find：返回迭代器
auto it = mp.find("Tom");
if (it != mp.end()) {
    cout << it->first << " " << it->second;  // key 和 value
}

// 3. 下标访问：key 不存在会【自动插入默认值 0】！
int v = mp["NotExist"];   // 危险：会插入 {"NotExist", 0}
```

## 五、删除

cpp

```
mp.erase("Tom");          // 按 key 删
mp.erase(it);             // 按迭代器删
mp.clear();               // 清空全部
```



## 六、遍历

cpp

```cpp
// 有序遍历（map 按 key 升序）
for (const auto& [key, val] : mp) {
    cout << key << " -> " << val << "\n";
}

// 传统写法
for (auto it = mp.begin(); it != mp.end(); ++it) {
    cout << it->first << " -> " << it->second << "\n";
}
```



`auto& [key, val]` 是 **结构化绑定**（C++17），`key` 是 `first`，`val` 是 `second`。

## 七、常用成员函数

| 函数            | 作用                           |
| :-------------- | :----------------------------- |
| `mp[key]`       | 访问/插入，不存在则创建默认值  |
| `mp.at(key)`    | 访问，不存在抛异常             |
| `mp.count(key)` | 返回 0 或 1                    |
| `mp.find(key)`  | 返回迭代器，找不到返回 `end()` |
| `mp.erase(key)` | 删除                           |
| `mp.size()`     | 元素个数                       |
| `mp.empty()`    | 是否为空                       |
| `mp.clear()`    | 清空                           |

## 八、完整示例：统计单词出现次数

cpp

```cpp
#include <iostream>
#include <unordered_map>
#include <string>
#include <vector>
using namespace std;

int main() {
    vector<string> words = {"apple", "banana", "apple", "cherry", "banana", "apple"};

    unordered_map<string, int> cnt;
    for (const auto& w : words) {
        cnt[w]++;              // 不存在时自动创建为 0，再 ++
    }

    for (const auto& [word, c] : cnt) {
        cout << word << ": " << c << "\n";
    }
}
```



输出（顺序不定，因为是 unordered）：

text

```
apple: 3
banana: 2
cherry: 1
```



## 九、和 Java, c#  对照

| 操作     | C++                             | Java                                        | C#                                       |
| :------- | :------------------------------ | :------------------------------------------ | :--------------------------------------- |
| 创建     | `unordered_map<string,int> mp;` | `Map<String,Integer> mp = new HashMap<>();` | `var mp = new Dictionary<string,int>();` |
| 赋值     | `mp["a"] = 1;`                  | `mp.put("a", 1);`                           | `mp["a"] = 1;`                           |
| 读取     | `mp["a"]`                       | `mp.get("a")`                               | `mp["a"]`                                |
| 是否存在 | `mp.count("a")`                 | `mp.containsKey("a")`                       | `mp.ContainsKey("a")`                    |
| 删除     | `mp.erase("a");`                | `mp.remove("a");`                           | `mp.Remove("a");`                        |
| 遍历     | `for (auto& [k,v] : mp)`        | `for (var e : mp.entrySet())`               | `foreach (var kv in mp)`                 |
| 长度     | `mp.size()`                     | `mp.size()`                                 | `mp.Count`                               |

## 十、常见坑

1. **`mp[key]` 会插入默认值**，只想查用 `find` / `count` / `at`
2. `unordered_map` 遍历顺序**不确定**，别依赖顺序
3. 自定义类型作 key，`unordered_map` 要提供哈希函数，`map` 要提供 `<` 比较
4. `map` 的 key 是 **const**，不能改 key，只能改 value

## 十一、一句话总结

> 要排序用 `map`，要快用 `unordered_map`；
> 插入用 `mp[k] = v` 或 `emplace`；
> 查找用 `count` / `find`，**别用 `[]` 做纯查询**；
> 遍历用 `for (const auto& [k, v] : mp)`。
